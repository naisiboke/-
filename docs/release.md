# 发布状态与验收

## 已验证的开发能力

- uni-app H5 客户端：首页、四步记录、规则复盘、状态反馈、历史列表、设置及 AI 发送预览。
- 六类冲突各三个本地情境模板，核心逻辑不发网络请求。
- 临时记录、草稿、编辑、删除；全部仅在内存中。刷新即丢失，界面明确告知。
- 独立 AI 网关原型：Node 24 内置 SQLite 额度账本、令牌哈希、幂等键、失败退款、超时及结构校验。账本不保存正文或 AI 输出。
- 加密备份算法：WebCrypto AES-256-GCM、PBKDF2-SHA256 310000 轮、随机 salt 与 IV，错误密码/篡改拒绝。尚未接原生文件流程。

## 本地命令

```sh
npm ci
npm run dev:h5
# 另开终端
npm test
npm run typecheck
npm run build:h5
npm run test:e2e
npm run server
```

浏览器测试默认使用 /usr/bin/chromium；其他系统在 playwright.config.ts 配置本机浏览器路径或安装 Playwright Chromium。运行 e2e 前先启动 H5 开发服务。
服务默认仅监听 127.0.0.1:8787；GET /health 返回服务状态。未配置模型时 POST /v1/reflections 返回 503 NOT_CONFIGURED，不发起模型调用。

## 服务部署前必须完成

- 模型选择、输出质量与留存条款审阅；安全注入 MODEL_API_URL（完整 HTTPS chat/completions URL）、MODEL_API_KEY、MODEL_NAME；不得提交密钥。
- CARETRUCE_DB 必须指向持久化私有目录。当前 SQLite 方案仅允许一个活动进程；进程互斥保护尚待接入，禁止启动第二个进程。多进程部署前迁移到具有可靠事务的共享账本并重做恢复策略。
- HTTPS 反向代理、边缘流量限制、防滥用、监控告警和成本限额。没有配置服务上线域名，未部署公网服务。
- CARETRUCE_ALLOWED_ORIGIN 按精确 Web 来源配置；原生环境仍须验证每安装身份机制，不能用 CORS 代替鉴权。
- 不存在客户端共享令牌。当前仅有内部账本 issue 方法用于测试，未开放公网发放额度接口；正式版需补安装身份、恢复策略与商店验证的权益授予。不得把测试令牌内置客户端。
- 同一进程内成功结果可在两分钟内用原幂等键重取，不再次扣费；原始结果仅保存在有限的临时内存中。过期、缓存容量淘汰或进程重启后返回 409；跨进程重启的结果恢复仍是收费上线阻塞项，不得自动换新键再次扣费。

## 原生与收费阻塞

- 取得 iOS/安卓加密 SQLite 与密钥存储适配，真机验证重启、应用锁、后台隐私、卸载及系统备份排除。
- 依据所选插件确定传统 uni-app 与 UTS 原生模块边界；不能把 H5 构建通过等同 App 真机可用。
- 配置真实 AppID、签名、macOS/Xcode、开发者账号；确认安卓商店与主体要求。
- StoreKit/安卓渠道支付、服务端签名与交易校验、通知幂等、退款与恢复购买。
- AI 消耗额度重装/换机恢复，与非消耗买断的恢复购买分别设计和验证。
- 原生 PDF、文件分享、加密备份恢复 UI 与原子导入；只有算法测试不代表备份功能交付。
- 隐私政策、条款、支持联系方式、模型处理方、保留期限、适用地区备案与审核材料。

当前是可运行开发版本，不是已发布或可收费的正式版本。没有进行真实模型调用、交易、真机验证或商店提交。
